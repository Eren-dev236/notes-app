# 🐱 Cat Notes App

A cute and cozy full-stack Notes application built with Flask, SQLite, HTML, CSS, and JavaScript.

## ✨ Features

- 📝 Create and save notes
- 💾 Store notes in a SQLite database
- 📖 Display saved notes
- 🔍 Search through saved notes
- 🗑️ Delete notes
- 🐱 Cute cat-themed interface
- 🎀 Cozy and responsive design
- 🐾 Different cat illustrations throughout the app

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Version Control:** Git & GitHub
